## 💻 Local Development

If you want to run this documentation site locally, follow these steps:

### Prerequisites
- Node.js (version 18.0 or above)

### Installation
```bash
# Clone the repository
git clone [https://github.com/thezahidul/odoo-apps-portfolio.git](https://github.com/thezahidul/odoo-apps-portfolio.git)

# Go into the project directory
cd odoo-apps-portfolio

# Install dependencies
npm install
